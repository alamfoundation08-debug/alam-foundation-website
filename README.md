## Free publishing using GitHub Pages
1. Sign in/create an account at https://github.com/
2. Create a **public** repository, for example `alam-foundation-website`.
3. Upload `index.html`, `styles.css`, `script.js`, `README.md` and the `assets` folder to the repository root.
4. Open **Settings → Pages** in the repository.
5. Under build/deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will usually look like `https://YOUR-USERNAME.github.io/alam-foundation-website/`.
7. Open that URL and check every section and link.

GitHub’s interface may change. GitHub Pages hosting is free for public repositories, but the exact URL depends on your GitHub username and repository name. You must create the account/repository and enable Pages yourself.
