- The donation section and online payments are not included.

## Publish with GitHub Pages
1. Create a public repository.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. Go to **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. Wait for GitHub Pages to publish and open the URL it provides.
